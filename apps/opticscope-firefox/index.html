FIRST AUDIO SETUP

  1. Select DESKTOP AUDIO, MICROPHONE, or AUDIO FILE.
  2. For YouTube, share the browser tab when possible and enable shared audio when your browser offers it. Firefox may provide video-only screen sharing; use MICROPHONE or AUDIO FILE if no audio track is available.
  3. Start in TIME mode to confirm audio is reaching the scope.
  4. Switch to X-Y. Stereo material uses left audio for X and right audio for Y.
  5. Use GAIN first, then X GAIN and Y GAIN to fit the trace inside the screen.

HOW AN OSCILLOSCOPE WORKS

In TIME mode, the beam moves horizontally at a controlled sweep rate while the audio voltage moves it vertically. A repeating signal can look unstable unless the trigger begins each sweep at nearly the same point.

In X-Y mode, the normal sweep is removed. One signal controls horizontal movement and another controls vertical movement. A stereo waveform can therefore draw loops, Lissajous figures, and complete vector artwork.

X-Y CALIBRATION

X GAIN
Controls the width of the figure without changing its height.
Y GAIN
Controls the height of the figure without changing its width.
ROTATION
Turns the complete X-Y image clockwise or counterclockwise.
PHASE
Offsets the Y signal relative to X. Start at −180°. Move it slowly when a figure looks collapsed, twisted, or mirrored.
Z-AXIS AUTO SPIN
Continuously rotates the complete drawing. Leave it off while calibrating, then enable it as an effect.
INVERT Y
Flips the image vertically. Use it when text or artwork appears upside down.
AUTO LEVEL X-Y
Automatically enlarges quiet incoming signals. Turn it off when you need fixed, repeatable calibration.

BEAM AND PHOSPHOR

GAIN
Overall trace size. Too much gain pushes the drawing beyond the CRT edges.
FOCUS
Controls beam sharpness. Higher values create a thinner, more precise trace; very high values can make dim details harder to see.
INTENSITY
Controls the brightness of the active trace.
PERSISTENCE
Controls how long previous beam positions remain. Lower values look crisp and fast; higher values leave longer trails.
PARTICLE AMOUNT
Adds small phosphor sparks around the active beam. Keep this low for detailed PNG outlines.
PARTICLE DECAY
Controls how long particles remain visible.
PARTICLE DRIFT
Controls how far particles float away from the trace.

PNG DETAIL OUTLINE

Paste or load a PNG, JPG, or WebP in ART LAB. The image processor searches the complete picture for visible contrast boundaries, not only the outside silhouette. It can trace internal shapes, text, facial features, transparent boundaries, and strong shading changes.

  1. Load or paste an image and wait for the green preview.
  2. Raise IMAGE DETAIL for small features. Start around 224–320.
  3. Keep EDGE THINNING at 1 for maximum detail. Increase it only when lines become doubled or noisy.
  4. Raise EDGE DETAIL to include weaker features. Lower it when the result becomes cluttered.
  5. Use EDGE STRENGTH around 0.90–1.20.
  6. Increase VECTOR SPOTS when curves or lettering look blocky. Start around 12,288 and raise it gradually.
  7. Set SIGNAL GENERATOR smoothing to 0 or 1 for sharp image outlines.
  8. Press PLAY OUTLINE, then adjust beam gain and X-Y calibration.

WHY IMAGE OUTLINES CAN LOOK WRONG

A real X-Y beam cannot teleport between disconnected details. It must travel from one contour to the next, which may create short connecting lines. The program orders contours to reduce those jumps, but simple high-contrast artwork will still produce the cleanest result.

ONLY A FEW LINES APPEAR
Increase EDGE DETAIL, IMAGE DETAIL, and VECTOR SPOTS.
THE PREVIEW IS TOO BUSY
Lower EDGE DETAIL or increase EDGE THINNING.
TEXT IS HARD TO READ
Use a larger source image, set smoothing to 0, and increase VECTOR SPOTS.
THE IMAGE FLICKERS
Increase TRACE RATE slightly. Extremely detailed paths may need a lower point count or fewer detected edges.
THE IMAGE IS STRETCHED
Correct it with X GAIN and Y GAIN.

SIGNAL GENERATOR

TRACE RATE
How many times per second the complete art path is redrawn. Faster rates can look steadier but produce a higher audio pitch.
POINTS
General vector resolution for presets, drawings, and SVG artwork.
SMOOTHING
Rounds corners and removes jitter. Use 0–1 for detailed PNGs and higher values for flowing shapes.
OUTPUT LEVEL
Audio level of generated stereo art. Keep it below 50% when connecting to real hardware, then raise carefully.

FULLSCREEN AND RECORDING

FULLSCREEN VISUAL expands only the CRT display. Recording captures the visual in the selected aspect ratio and includes generated or connected audio when the browser provides it.

REAL HARDWARE SAFETY

Use a normal audio interface or headphone output at a low level. Never connect an oscilloscope directly to mains electricity or an unknown high-voltage circuit.
