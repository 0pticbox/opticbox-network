DISTORTION v1.3 — DATAMOSH BANK UPDATE

Open index.html in a modern desktop browser.

CHANGES
- Rebuilt effects around randomized datamosh/glitch corruption.
- Number keys 1–9 now control the main distortion bank.
- Backslash keeps Negative Strobe as a bonus effect.
- Removed Vortex Shredder, Random Slicer, Infinite Tunnel, and the old kaleidoscope-heavy bank.
- Split Zoom+ now has an extra left-side video block.
- Scene/hot-cue pads moved into the left sidebar.
- Click a scene pad to select/deselect it.
- Shift-click a saved scene pad to jump to it.
- Right-click a scene pad to clear only that scene.
- Select a scene, then Shift-click the timeline to save or replace that exact scene.
- Layout is compressed to fit a normal desktop viewport more cleanly.

V1.4 DRAMATIC TRANSITIONS / CUSTOM MAPS
- Transition impact strength control added.
- Transition keyboard keys can be remapped in the Transitions panel.
- Custom transition maps are remembered by the browser.
- Conflicting scene/effect keys are blocked.
- Drag the vertical divider edges to resize left and right control panels.
- Drag the lower edge/corner of the output and timeline areas to resize vertically.

V1.6 UPDATE
- New condensed display/UI font stack for a cleaner performance-console look.
- Three switchable themes: Acid Terminal, Magenta Damage, and Ice Signal.
- Theme choice is remembered in the browser.
- Hot cues, right-click removal, custom transition mapping, and resizable panels remain unchanged.


v1.7 THEME OVERHAUL
- Acid Terminal now uses industrial CRT scanlines, clipped controls, toxic green lighting, and console-style panels.
- Magenta Damage now uses loud cyber-club geometry, offset cyan shadows, skewed headers, and neon active states.
- Ice Signal now uses a bright frozen broadcast-lab layout with translucent glass panels, rounded controls, and a light interface.


V1.8 FOUR THEME / ENVIRONMENT UPDATE
- Studio is now the clean default theme with no animated environment.
- Acid Bunker adds a CRT server-bunker environment, scanlines, hardware silhouettes, and drifting signal dust.
- Punk District adds an abandoned neon venue, graffiti typography, moving lasers, and low smoke.
- Corrupted Signal adds an original infernal broadcast environment with volcanic glow, ash, heat haze, and jagged silhouettes.
- Theme font slots: Sandey Molse (Studio), Pickyside Grunge (Acid), Very Very Punk (Punk), and WESAYSO (Corrupted).
- Font files are not bundled. If those fonts are installed on the computer, the app uses them automatically; otherwise it uses matching fallbacks.
- Existing hot cues, right-click removal, custom transition mappings, effects, recording, and resizable panels remain intact.


V1.9 MIRROR DAMAGE UPDATE
- Replaced Mosh Burst (2) with MIRROR SHARDS.
- Kept MIRROR GRID (3) and added MIRROR HALL (9), giving the bank three distinct mirror effects.
- Replaced RGB Damage (7) with NEGATIVE TEAR, a shifted inverted-strip effect with a moving diagonal signal rip.
- Strengthened NEGATIVE PULSE+ (8) so it behaves more like the backslash family without copying the strobe exactly.
- Strengthened NEGATIVE STROBE (\) with irregular difference bands and a harsher cadence.
- Preserved Color Crush, Split Zoom+, Block Detonator, hot cues, custom transitions, resizable panels, and all four themes.


V1.9.1 VIDEO / COLOR FIX
- Effect 7 is now VIDEO TEAR. Every displaced block and diagonal tear is sampled from the live video; the flat difference-color blocks were removed.
- Effect 9 is now COLOR SURGE, with animated hue rotation, saturation, color echoes, and video-derived color bands.
- All hot cues, themes, custom transition maps, recording, and resizable panels remain unchanged.

V1.10 EXPORT FORMAT / MAXIMUM QUALITY UPDATE
- Recording format menu now detects and lists only encoders supported by the current browser.
- Choose MP4 H.264/AAC when available, WebM VP9, WebM VP8, or Auto.
- Added Maximum, High, and Standard recording-quality profiles.
- Maximum requests 80 Mbps video and 320 kbps audio at the full canvas resolution and 60 FPS.
- The app no longer forces WebM or a fixed 12 Mbps bitrate.
- Browser MediaRecorder still uses a codec; Maximum is the least-compressed browser export, not mathematically uncompressed raw video.
- Recording format, quality, and aspect controls lock while recording to prevent mismatched output.


V1.11 DEFAULT TRANSITION / HELP UPDATE
- Hot cues no longer force Zoom Punch. The user can choose the automatic Default Cue Transition.
- White Flash is the starting default transition and is mapped to T.
- Default transition shortcuts are now T, Y, U, I, O, and P.
- Transition keys remain custom-mappable and can be reset with RESET TO T–P MAP.
- The selected default transition is remembered by the browser.
- Added a None — Hard Cut option for cue jumps without an automatic transition.
- Expanded the Help page with a dedicated Transitions guide and complete effect/keyboard maps.


V1.12 UNIVERSAL FX STACK UPDATE
- Fixed Mirror Grid (3) erasing Negative Pulse+ (8).
- Rebuilt the entire numbered FX bank as a pass-by-pass compositing chain.
- Every active effect now receives the completed result of the previous effect.
- Effect combinations mix consistently regardless of key-press order.
- Mirror, negative, color, tear, split, block, strobe, and datamosh effects can all be stacked together.
- Existing hot cues, transition mapping, recording formats, themes, help page, and resizable panels remain unchanged.
