SPECTRAVAULT FIELD MANUAL

Turn sound into a live visual transmission.

Connect audio, choose a visual core, stack distortion keys 1–9, place your logo, and record a clean video with no added watermark.

01

Connect audio

Use MIC, load an AUDIO FILE, or choose DESKTOP / TAB. When sharing a tab or screen, enable the browser's audio-sharing option when one is offered. Some shared sources may provide video without audio, so MIC and AUDIO FILE remain available as reliable audio sources.

02

Shape the visual

The engine includes eight core looks: Kaleido Reactor, Neon Tunnel, Water Drift, Vector Scope, Aurora Ribbons, Pulse Rings, Cube Matrix, and Pyramid Spire. Auto Flow uses a slower equal-power crossfade, Pulse Rings includes adaptive performance protection targeting smooth 60 FPS at high settings, Pyramid Spire adds a spinning wireframe pyramid family related to the cube visual, and Picture in Picture can float the visual over other apps. When the standard PiP web API is unavailable, the same button opens a detachable floating visual window. Use the top-right theme buttons to switch between Chrome Bubble and Rave Worm.

03

Perform with FX

Press keys 1–9 or click the distortion pads. Effects can be stacked. Auto Feedback continuously shifts the trail depth for hands-free movement. Press CLEAR ALL FX to reset the chain.

04

Record and export

Select YouTube, vertical, or square output, then press RECORD. The downloaded video contains the visual, logo, and connected audio. MP4 is used when supported; WebM is used automatically when needed.

DISTORTION BANK

Keyboard controls 1–9

1

2

Adds horizontal tracking slices, jitter, and scan lines.

3

Prism Shift

Adds iridescent displaced layers and moving refracted bands without washing out the frame.

4

Pixel

Crushes the image into chunky low-resolution blocks.

5

Mirror

Reflects the frame for a symmetrical stage look.

6

Wave

Bends horizontal bands into a moving signal wave.

7

Scan Pulse

Sweeps a moving refracted distortion band across the visual without full-screen flashing.

8

Echo

Stacks delayed frames into expanding feedback trails.

9

Thermal Map

Recolors the existing light and shadow with a moving heat-style palette.

LOGO LAYER

Brand the performance

Load a transparent PNG for the cleanest result. Drag the logo directly on the visual. Use size, opacity, and spin to match the scene.

TIP Keep important logo details away from the extreme edges for vertical crops.

RECORDING

Clean, watermark-free output

SPECTRAVAULT adds no watermark. It checks the browser encoder at runtime: MP4 is preferred when available, with an automatic WebM fallback when needed. For smoother recording, keep this tab visible, close heavy background apps, and use 720p when the computer struggles at 1080p.

TROUBLESHOOTING

When audio is not reacting

  • Click the audio source again and approve browser permission.
  • For desktop audio, select a browser tab or screen and enable audio sharing.
  • Use a current Chromium-based desktop browser for the best results.
  • If local-file permissions fail, run python -m http.server 8080 inside the folder.
