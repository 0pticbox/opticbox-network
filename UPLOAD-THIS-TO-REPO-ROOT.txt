0PTICBOX NETWORK v27 — ARTIST TOTAL FOLLOWERS

UPLOAD
======
Upload the CONTENTS of this ZIP to the ROOT of the opticbox-network GitHub repository.
Replace matching files. Keep your existing supabase-config.js.

WHAT CHANGED
============
1. Every member profile now has a Total Followers stat beside the Joined stat.
2. Total Followers = Instagram followers + YouTube subscribers.
3. Artists can enter both public counts from Profile Settings.
4. The profile formats large totals cleanly (for example 16.7K) while the hover/title keeps the exact Instagram + YouTube breakdown.
5. If both counts are blank, the profile shows a dash instead of pretending the member has zero followers.
6. 0PTICBOX uses the exact same follower-count system as every other member.

WHY COUNTS ARE ENTERED BY THE MEMBER
=====================================
The site is static-hosted and Instagram does not provide a reliable no-login public follower-count endpoint. YouTube's live count also requires API credentials. Manual public counts avoid fragile scraping and keep API keys out of the browser.

SUPABASE
========
Run supabase/2026-08-profile-follower-counts.sql once in the Supabase SQL Editor.
It is safe to run more than once.
