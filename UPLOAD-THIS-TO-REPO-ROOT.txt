0PTICBOX NETWORK v26 — BACKGROUND OWNERSHIP FIX

UPLOAD
======
Upload the CONTENTS of this ZIP to the ROOT of the opticbox-network GitHub repository.
Replace matching files. Keep your existing supabase-config.js.

WHAT CHANGED
============
1. The main Opinion Hub / feed (index.html) now reads background_gif_url from the existing Admin Site Background setting.
2. The Admin-selected GIF/image is therefore the default background whenever someone is on the main feed.
3. Member profile pages ignore the Admin/feed background and render that member's own background_url GIF/image instead.
4. Going Back/Home to the feed restores the Admin-selected background automatically.
5. Members who have not selected a personal wallpaper still use the neutral built-in profile fallback.

SUPABASE
========
No new SQL migration is required for v26. It uses the existing site_content.background_gif_url Admin setting and the existing profile wallpaper fields from v25.

ADMIN
=====
Use Admin Dashboard > Site background GIF to choose the feed background. Save it, then refresh the feed.
