OPTICBOX NETWORK v29 — COMBINED INSTAGRAM + YOUTUBE TOTAL

WHAT CHANGED
1. TOTAL FOLLOWERS is explicitly calculated as Instagram followers + YouTube subscribers.
2. Profile Settings now shows a live Combined Audience preview so artists can see the exact math before saving.
3. The public profile tooltip/accessible label shows the exact Instagram + YouTube breakdown.
4. Added compatibility aliases for older YouTube subscriber field names.
5. No new Supabase SQL is required if you already ran the v27/v28 follower-count migration.

IMPORTANT
A YouTube channel URL by itself does not contain a subscriber count. Enter the artist's current YouTube subscriber count in Profile Settings > YouTube subscribers. Once saved, it is added to Instagram automatically.
