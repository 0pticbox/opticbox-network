WHAT CHANGED
- Every member now gets the same full two-column profile layout that 0PTICBOX uses.
- opticbox.html now opens the same shared member-profile template instead of a special page.
- Members can add a featured project/song/app/link.
- Members can add "Who I'd Like to Meet" entries.

- Members can connect YouTube and embed up to 3 videos/playlists.
- Existing wallpaper, avatar, accent color, interests, links, messages, posts, and reviews stay in place.
- The v23 friendly database-error fallback remains.

IMPORTANT
Instagram/YouTube embeds only display content that those services allow to be embedded publicly.
Private/deleted posts or videos with embedding disabled will not render.
