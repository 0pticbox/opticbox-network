OPTICBOX v32 — 0PTIC'S AUDIO BRIDGE
===================================

The Firefox versions of 0PTICSCOPE, 0PS3, and SPECTRAVAULT now start in
0PTIC'S AUDIO BRIDGE mode by default.

WINDOWS BETA FLOW
1. Download 0ptics-audio-bridge-windows.zip from FREE TOOLS or a Firefox app.
2. Extract it.
3. Double-click START 0PTICS AUDIO BRIDGE.cmd.
4. Keep the bridge window open.
5. Launch the Firefox version of the visualizer.
6. The status changes to BRIDGE CONNECTED when localhost:17491 responds.
7. Play music through the normal Windows default speakers/headphones.

The original AUDIO INPUT, AUDIO FILE, and SCREEN AUDIO options remain as
fallbacks.

IMPORTANT BETA LIMITATION
This first bridge proves the computer-output path by reading the Windows
output meter and sending level + derived motion bands to the visualizer.
It does not send the raw system-audio waveform into Firefox yet, so recordings
made in Bridge mode do not contain the computer's audio track.

No Supabase changes are required.
