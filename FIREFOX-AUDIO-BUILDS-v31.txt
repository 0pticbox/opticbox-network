0PTICBOX NETWORK v31 — DEDICATED FIREFOX AUDIO BUILDS

Dedicated Firefox browser versions were added for:
- 0PTICSCOPE
- 0PS3 Visualizer
- SPECTRAVAULT

The normal app folders remain the Chrome/Chromium launch targets.
Firefox variants live in:
- apps/opticscope-firefox/
- apps/0ps3-firefox/
- apps/spectravault-firefox/

Firefox-specific audio behavior:
- The app still tries screen audio when Firefox provides it.
- If Firefox returns screen video without audio, it gives a clear message instead of silently failing.
- Each Firefox build has an Audio Input Device selector.
- Users can choose a microphone or any loopback/Stereo Mix/virtual audio input that the OS exposes through getUserMedia().
- Audio File remains fully supported.
- Recording uses Firefox-friendly WebM fallback already introduced in v30.

Important browser limitation:
A web page cannot force Firefox to expose system audio through getDisplayMedia(). The dedicated build works around that limitation by allowing a selectable audio-input/loopback device rather than pretending screen audio is available.
